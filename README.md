## About

I’m a backend-focused engineer. I work mainly with **Python** and **Django**, **APIs**, and **AI/ML** that reaches production—not just notebooks.

I like clear requirements, straightforward architecture, and code that’s easy to change later. I care about tests, logging, and migrations that don’t scare the team.

**Ask me about:** Django, Postgres, queues, API design, or how I’d roll out an ML feature safely.
